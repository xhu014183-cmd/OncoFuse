输入影像与检验 · 获取解读auditable 主链路

上传 CT（.nii.gz） + 可选肿瘤 mask（.nii.gz） + 检验报告（.txt）， 按 LiON-inspired → GLM → 交叉检查 → 检验融合 → 受控报告链路生成解读。

等待输入 · 需 vlm-web 服务

选择 CT 和检验文件后点击「开始解读」；不提供 mask 时定量证据会标记为不可用，不会解释为无病灶。

队列研究 / TACE 后总生存风险（独立研究合同）

新增链路使用 WAW-TACE 开发、HCC-TACE-Seg 锁定外部验证；比较临床、影像和融合的 惩罚 Cox 模型。GLM 仅解释重新渲染的 CT，DeepSeek 仅润色锁定报告，两者均不参与生存预测。

研究输入

同一受试者的基线 CT、公开参考 SEG、年龄、性别和 AFP，以及冻结的 JSON 模型包。 结局字段会被接口拒绝。

研究输出

相对风险指数、WAW 开发队列百分位和中位风险分层；不输出“还能活多久”。 结果永久显示回顾性研究与人工复核限制。
接口与复现入口

POST /api/prognosis；命令行使用 hcc-demo run-prognosis-report。 完整下载、训练和外部验证命令见 README 与 docs/HCC_PUBLIC_OS_PROTOCOL.md。
